# customer-trends-data-analysis-SQL-Python-PowerBI
This project focuses on analyzing customer shopping behavior to identify purchasing patterns, customer preferences, and sales trends. By using SQL, Python, and Power BI, the project transforms raw customer transaction data into meaningful business insights that can help organizations make data-driven decisions.

🎯 Project Objectives

Analyze customer purchasing behavior and shopping patterns.

Identify trends in purchase amounts and product categories.

Understand the impact of discounts and promotional offers on customer spending.

Analyze customer preferences based on demographics and shopping habits.

Generate actionable business insights to support strategic decision-making.

🛠️ Tools & Technologies

SQL (PostgreSQL): Data querying, filtering, aggregation, and analysis.

Python: Data cleaning, preprocessing, and exploratory data analysis.

Pandas & NumPy: Data manipulation and analysis.

Power BI: Interactive dashboards and data visualization.

Jupyter Notebook: Python-based data analysis.

📊 Key Analysis Areas

Customer purchasing behavior.

Product category performance.

Average purchase amount analysis.

Discount and promotional code effectiveness.

Customer segmentation.

Shopping frequency and purchase trends.

💡 Key Outcomes

Identified important customer purchasing patterns.

Explored the relationship between discounts and spending behavior.

Analyzed product and category-level performance.

Developed insights to understand customer preferences.

Presented analytical findings through interactive Power BI dashboards.

📁 Project Workflow

Data collection and understanding.

Data cleaning and preprocessing using Python.

Exploratory Data Analysis (EDA).

Data analysis using SQL queries.

Dashboard creation using Power BI.

Business insights and conclusions.

🚀 Skills Demonstrated

SQL | Python | PostgreSQL | Data Cleaning | EDA | Data Analysis | Pandas | NumPy | Power BI | Data Visualization | Business Intelligence
